# 产品路线图 / Product Roadmap

> 整理日期 / Updated: 2026-11-19
> 产品定位：本地优先、隐私可控的「数据分析 + 知识沉淀」Agent

## 一、已完成 / Completed

| 模块 | 能力 |
|---|---|
| 数据接入 | CSV/JSON/Excel 上传、粘贴、内置示例 |
| 分析引擎 | 查询/趋势/异常/对比/概览 5 类分析，DDD 枚举值对象 |

| Embedding | 本地 bge-small-zh-v1.5 ONNX，零外部依赖 |
| 存储 | DuckDB（分析）+ H2/SQLite（元数据）+ Zvec（双 collection 向量）|

| 前端 | 数据集管理、图表、知识库三视图 |
| 部署 | 单 jar 常驻、本地部署文档 |
| 文档 | README / 知识库 / 本地部署 / DDD 模型 |

## 四、方向决策依赖 / Decisions Needed

以下功能是否做，取决于产品方向拍板：

- **多用户/权限（12）**：取决于"单人工具 vs 团队产品"
- **公网部署（13）**：取决于"本地工具 vs 公网 SaaS"
- **JDBC 直连（4）**：取决于"文件上传够用 vs 真实业务库接入"
- **文档入库（3）**：取决于"手动录入够用 vs 知识规模化"
